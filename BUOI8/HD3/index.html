Hoạt động 3 - Sử dụng AI để giải thích logic lập trình

Thời gian thực hiện: 30 phút

1. Mục tiêu hoạt động

Sử dụng AI để phân tích mã JavaScript, giải thích luồng chạy của chương trình bằng ngôn ngữ tự nhiên và phát hiện lỗi lập trình.

Thông qua hoạt động, sinh viên hiểu rõ hơn cách sử dụng vòng lặp, điều kiện, hàm và mảng.

2. Ví dụ 1 - Tính tổng bằng vòng lặp

let tong = 0;

for (let i = 1; i <= 5; i++) {
    tong = tong + i;
}

console.log(tong);
Giải thích của AI:
  • tong = 0: Khởi tạo biến tổng.
  • i = 1: Bắt đầu vòng lặp từ 1.
  • i <= 5: Lặp khi i nhỏ hơn hoặc bằng 5.
  • i++: Tăng i lên 1 sau mỗi lần lặp.
  • tong = tong + i: Cộng i vào tổng.
Kết quả: 15

3. Ví dụ 2 - Lọc dữ liệu trong mảng

let numbers = [2, 4, 6, 8, 10];

let result = numbers.filter(function(num) {
    return num > 5;
});

console.log(result);
Giải thích của AI:
  • numbers: Danh sách các số ban đầu.
  • filter(): Lọc các phần tử trong mảng.
  • num > 5: Điều kiện giữ lại số lớn hơn 5.
  • return: Trả về điều kiện kiểm tra.
Kết quả: [6, 8, 10]

4. Ví dụ 3 - Phát hiện và sửa lỗi

5. Ví dụ 4 - Đếm số điểm đạt yêu cầu

let diem = 0;
let danhSach = [7, 8, 4, 9, 5];

for (let i = 0; i < danhSach.length; i++) {
    if (danhSach[i] >= 7) {
        diem++;
    }
}

console.log("So diem dat:", diem);
Giải thích của AI:
  • diem = 0: Khởi tạo biến đếm.
  • danhSach: Chứa 5 điểm số.
  • length: Lấy số lượng phần tử trong mảng.
  • for: Duyệt qua từng phần tử.
  • if: Kiểm tra điểm có >= 7 hay không.
  • diem++: Tăng biến đếm lên 1 nếu đạt điều kiện.
Kết quả: So diem dat: 3
