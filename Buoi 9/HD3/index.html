Hoạt động 3: Tái cấu trúc code (Refactoring)

Đóng gói logic tính thuế thu nhập cá nhân vào một Hàm để tái sử dụng theo nguyên tắc DRY (Don't Repeat Yourself).

Đoạn mã đã được đóng gói thành hàm:

function tinhThueThuNhap(luong) {
    let thue = 0;
    if (luong > 15000000) {
        thue = luong * 0.15; // 15% thuế
    } else if (luong >= 9000000) {
        thue = luong * 0.10; // 10% thuế
    } else {
        thue = 0; // Miễn thuế
    }
    return thue;
}
