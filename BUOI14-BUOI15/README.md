# SHOE STORE – WEBSITE BÁN GIÀY

## 1. Giới thiệu

SHOE STORE là website bán giày đơn giản được xây dựng nhằm thực hành kiến thức HTML, CSS và JavaScript trong môn Thiết kế Web.

## 2. Cấu trúc thư mục

```text
WEB-BAN-GIAY/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 3. Công nghệ sử dụng

- HTML5: Xây dựng cấu trúc website.
- CSS3: Thiết kế giao diện bằng Flexbox, Grid và Responsive.
- JavaScript: Xử lý dữ liệu, sự kiện và tương tác.
- Object và Array: Quản lý thông tin sản phẩm.

## 4. Chức năng chính

1. Hiển thị danh sách 10 sản phẩm.
2. Tìm kiếm sản phẩm theo tên.
3. Lọc sản phẩm có giá trên 1 triệu đồng.
4. Hiển thị lại toàn bộ sản phẩm.
5. Thêm sản phẩm vào giỏ hàng (mô phỏng bằng thông báo).
6. Kiểm tra dữ liệu form đăng ký.
7. Hiển thị thông báo khi đăng ký thành công hoặc dữ liệu không hợp lệ.

## 5. Kiến thức JavaScript áp dụng

| Kiến thức | Vị trí sử dụng |
|---|---|
| Object | Khai báo thông tin từng sản phẩm |
| Array | Lưu danh sách sản phẩm |
| forEach() | Duyệt và hiển thị sản phẩm |
| filter() | Tìm kiếm và lọc sản phẩm |
| find() | Tìm sản phẩm theo ID |
| createElement() | Tạo thẻ sản phẩm |
| addEventListener() | Xử lý sự kiện |
| preventDefault() | Ngăn form tải lại trang |
| innerHTML | Cập nhật nội dung giao diện |
| textContent | Hiển thị thông báo |

## 6. Cách chạy website

1. Tải hoặc mở thư mục WEB-BAN-GIAY bằng Visual Studio Code.
2. Kiểm tra 4 file nằm cùng một thư mục.
3. Mở file `index.html` bằng Live Server.
4. Sử dụng các chức năng tìm kiếm, lọc sản phẩm và đăng ký.

## 7. Kiểm thử

- Kiểm tra danh sách sản phẩm có hiển thị đầy đủ không.
- Nhập tên sản phẩm để kiểm tra tìm kiếm.
- Nhấn nút lọc để kiểm tra giá sản phẩm.
- Để trống họ tên để kiểm tra Form Validation.
- Nhập email không có ký tự @ để kiểm tra thông báo lỗi.
- Mở website trên điện thoại để kiểm tra Responsive.
- Mở DevTools Console để kiểm tra lỗi JavaScript.

## 8. Kết luận

Thông qua bài thực hành, tôi vận dụng được HTML Semantic, CSS Grid/Flexbox và JavaScript để xây dựng một website có giao diện và chức năng tương tác cơ bản. Bài thực hành giúp củng cố kiến thức về Object, Array, các phương thức xử lý mảng và Form Validation.
