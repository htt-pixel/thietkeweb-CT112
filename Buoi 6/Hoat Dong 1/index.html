Chủ đề: CSS Refactoring

Tại sao phải Refactor CSS?

Trong quá trình phát triển, mã CSS thường bị "phình" ra do viết vội, copy-paste, hoặc thêm tính năng không có kế hoạch. Kết quả là file style.css chứa hàng trăm dòng thừa, khó bảo trì và dễ gây xung đột style.

AI Prompt gợi ý:

AI Prompt

"Giao diện đang bị lỗi hiển thị như ảnh trên iPhone 12, hãy phân tích nguyên nhân và đề xuất mã CSS sửa lỗi."

🛠 Các kỹ thuật CSS Refactoring cốt lõi

  • Loại bỏ thuộc tính thừa: Xóa rule CSS không dùng ở bất kỳ đâu trong HTML (dead code).
  • Tối ưu selector: Tránh selector quá dài như div.container ul li a.link — viết gọn thành class cụ thể hơn.
  • Gộp class có chung thuộc tính: Nếu .btn-primary và .btn-secondary cùng dùng border-radius: 4px, hãy tách ra class dùng chung .btn.
  • Dùng CSS Custom Properties (Variables): Thay các giá trị màu sắc, khoảng cách lặp lại bằng biến --color-primary, --spacing-md.
  • Tổ chức theo thứ tự logic: Base → Layout → Components → Utilities — giúp dễ tìm kiếm và chỉnh sửa.

Lỗi #1 · Layout

Vỡ khung Hamburger Menu trên mobile

Triệu chứng:

Trên màn hình < 480px, tên logo bị tràn sang nút hamburger, gây vỡ layout header.

Nguyên nhân:

Class .logo thiếu min-width: 0 và không có overflow: hidden + text-overflow: ellipsis.

❌ Trước (Bug)
.logo {
  font-size: 1.45rem;
  color: var(--text-slate-dark);
  font-weight: 700;
  /* Thiếu giới hạn overflow */
}
✅ Sau (Fixed)
.logo {
  font-size: 1.45rem;
  color: var(--text-slate-dark);
  font-weight: 700;
  min-width: 0;
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
🎨
Lỗi #2 · Contrast

Màu chữ khó đọc trên nền Parallax Banner

Triệu chứng:

Text trong .parallax-subtitle code dùng màu trắng trên nền rgba(255,255,255,0.2) — tương phản WCAG chỉ đạt 1.5:1 (cần ≥ 4.5:1).

Nguyên nhân:

Màu nền và màu chữ quá gần nhau, không đảm bảo tỷ lệ tương phản WCAG AA.

❌ Trước (Bug)
.parallax-subtitle code {
  background: rgba(255,255,255,0.2);
  color: #ffffff; /* Quá gần màu nền */
  padding: 2px 6px;
  border-radius: 4px;
}
✅ Sau (Fixed)
.parallax-subtitle code {
  background: rgba(0, 0, 0, 0.45);
  color: #fde68a; /* Vàng nhạt */
  padding: 3px 8px;
  border-radius: 4px;
  border: 1px solid rgba(253,230,138,0.3);
}
🖼
Lỗi #3 · Image

Avatar bị méo do thiếu object-fit

Triệu chứng:

Khi thay SVG bằng ảnh thật trong .avatar-circle, ảnh bị kéo méo vì thiếu object-fit: cover.

Nguyên nhân:

Class .avatar-circle img không được định nghĩa. Trình duyệt mặc định co giãn ảnh theo kích thước container.

❌ Trước (Bug)
.avatar-circle {
  width: 90px;
  height: 90px;
  border-radius: 50%;
  /* Thiếu rule cho ảnh bên trong */
}
✅ Sau (Fixed)
.avatar-circle {
  width: 90px;
  height: 90px;
  border-radius: 50%;
  overflow: hidden;
}
.avatar-circle img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center top;
  display: block;
}
