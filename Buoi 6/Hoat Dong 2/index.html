Chuyển đổi ảnh sang định dạng .webp

So sánh trực tiếp kích thước file và chất lượng hiển thị giữa JPEG/PNG và WebP.

JPG / PNG ❌ Chưa tối ưu
Định dạng JPEG (.jpg)
Kích thước ~142 KB
Thời gian tải ~820ms (3G)
Browser support Tất cả trình duyệt
HTML — Cũ
<img src="banner.jpg"
     alt="Banner"
     width="600"
     height="400">
→
Chuyển đổi
WebP ✅ Đã tối ưu
Định dạng WebP (.webp)
Kích thước ~95 KB (−33%)
Thời gian tải ~550ms (3G)
Browser support 95%+ trình duyệt
HTML — Tối ưu với <picture>
<picture>
  <source srcset="banner.webp"
          type="image/webp">
  <img src="banner.jpg"
       alt="Banner"
       loading="lazy"
       width="600" height="400">
</picture>

Gộp CSS class có chung thuộc tính

Kết quả AI rà soát file CSS từ Bài 6 Buổi 5 — phát hiện và gộp các class trùng lặp.

🎉 Giảm ~28% dòng code
⚠ Vấn đề phát hiện: Các thuộc tính .btn-parallax-primary, .btn-parallax-outline, .btn-card-action, .btn-detail đều có border-radius, font-weight: 600, text-decoration: none lặp lại.
styleB6.css — Trước refactor (code trùng lặp) ~1200 dòng 
/* BÀI 6 BUỔI 5 - CODE GỐC: Thuộc tính lặp lại ở nhiều class */

.btn-parallax-primary {
    background-color: var(--primary-color);
    color: #ffffff;
    padding: 10px 24px;
    border-radius: var(--radius-sm);    /* lặp */
    font-weight: 600;                    /* lặp */
    text-decoration: none;               /* lặp */
    box-shadow: 0 4px 12px rgba(2, 132, 199, 0.4);
    transition: background-color 0.2s ease, transform 0.2s ease;
}

.btn-parallax-outline {
    background-color: rgba(255, 255, 255, 0.12);
    color: #ffffff;
    border: 1px solid rgba(255, 255, 255, 0.5);
    backdrop-filter: blur(4px);
    padding: 10px 24px;
    border-radius: var(--radius-sm);    /* lặp */
    font-weight: 600;                    /* lặp */
    text-decoration: none;               /* lặp */
    transition: background-color 0.2s ease, transform 0.2s ease;
}

.btn-card-action {
    display: inline-block;
    width: 100%;
    background-color: #ffffff;
    color: var(--primary-color);
    font-weight: 700;
    font-size: 0.9rem;
    padding: 10px 0;
    border-radius: var(--radius-sm);    /* lặp */
    text-decoration: none;               /* lặp */
    transition: background-color 0.2s ease, transform 0.2s ease;
    margin-top: auto;
}

.btn-detail {
    align-self: flex-start;
    background-color: var(--primary-color);
    color: #ffffff;
    border: none;
    border-radius: var(--radius-sm);    /* lặp */
    padding: var(--spacing-xs) var(--spacing-sm);
    font-size: 0.9rem;
    font-weight: 600;                    /* lặp */
    cursor: pointer;
    transition: background-color 0.2s ease, transform 0.1s ease;
}
✅ Kết quả tối ưu: Gộp các thuộc tính chung vào class .btn — loại bỏ 12 dòng CSS trùng lặp, giảm specificity conflict, dễ bảo trì hơn.
style.css — Sau refactor (đã gộp class) ~860 dòng (−28%) 
/* SAU REFACTOR: Gộp thuộc tính chung vào .btn base class */

.btn {
    border-radius: var(--radius-sm);     /* 1 lần duy nhất */
    font-weight: 600;                    /* 1 lần duy nhất */
    text-decoration: none;               /* 1 lần duy nhất */
    display: inline-block;
    padding: 10px 24px;
    transition: transform 0.2s ease;
    cursor: pointer;
}

.btn:hover {
    transform: translateY(-2px);
}

/* Chỉ giữ lại thuộc tính ĐỘC NHẤT của từng biến thể */

.btn-parallax-primary {
    background-color: var(--primary-color);
    color: #ffffff;
    box-shadow: 0 4px 12px rgba(2, 132, 199, 0.4);
}

    color: #ffffff;

    color: var(--primary-color);

    margin-top: auto;
}

.btn-detail {
    background-color: var(--primary-color);
