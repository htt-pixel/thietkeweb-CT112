PERFORMANCE OPTIMIZATION

CSS TRANSFORM VS TOP/LEFT

TẠI SAO CHỌN TRANSFORM?

Sử dụng transform: translate() giúp trình duyệt render qua GPU (Hardware Acceleration), giảm tải CPU và tránh giật lag (Reflow/Repaint).

Cú pháp tối ưu: transform: translateY(-4px)

QUY TẮC REFACTORING

  • Thay thế top/left bằng translate(x, y)
  • Sử dụng will-change: transform khi cần thiết
  • Chỉ dùng hiệu ứng trên transform và opacity
