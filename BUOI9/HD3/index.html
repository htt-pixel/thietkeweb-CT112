Hoạt động 3 - Tái cấu trúc mã nguồn bằng AI

Thời gian thực hiện: 30 phút

1. Mục tiêu hoạt động

Sử dụng AI để cải tiến đoạn code tính thuế thu nhập bị lặp lại thành một hàm có thể tái sử dụng cho nhiều mức lương khác nhau.

2. Vấn đề của code ban đầu

let luongA = 8000000;
let thueA = luongA * 0.05;

let luongB = 15000000;
let thueB = luongB * 0.05;

let luongC = 25000000;
let thueC = luongC * 0.05;

console.log(thueA, thueB, thueC);
Nhận xét:
  • Code có nhiều phần tính toán lặp lại.
  • Khó sửa đổi khi công thức thay đổi.
  • Không thuận tiện khi thêm nhiều mức lương.

3. Giải pháp Refactoring

Sử dụng hàm tinhThue(luong) để đóng gói công thức tính thuế và tái sử dụng. 

function tinhThue(luong) {
    let thue = 0;

    if (luong <= 10000000) {
        thue = luong * 0.05;
    }
    else if (luong <= 20000000) {
        thue = 10000000 * 0.05
             + (luong - 10000000) * 0.10;
    }
    else {
        thue = 10000000 * 0.05
             + 10000000 * 0.10
             + (luong - 20000000) * 0.15;
    }

    return thue;
}
Giải thích:
  • function: Khai báo một hàm.
  • luong: Tham số đầu vào của hàm.
  • if / else if / else: Phân loại mức lương.
  • return: Trả về số tiền thuế.
